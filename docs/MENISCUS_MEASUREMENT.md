# Medial Meniscus Measurement Pipeline

## 1. Purpose
This module provides quantitative geometric measurement of the segmented medial meniscus. The measurements are intended to be used in later phases for correlation with osteoarthritis (OA) metrics, patient age, and sex.

## 2. Input
The pipeline requires a valid `image_id` that has already successfully passed through:
- Image Upload & Preprocessing
- Anatomical AI Segmentation

## 3. Segmentation Dependency
The measurement module expects a segmentation mask for the medial meniscus (class 3 in the overarching standard, but retrieved locally as a binary target). If this mask is missing, empty, or misaligned with the source image, the measurement aborts safely.

## 4. Measurement Locations
For prototype demonstration, three standardized locations are sampled across the horizontal bounding width of the detected meniscus:
- **Location A:** 25% across the width
- **Location B:** 50% across the width (midpoint)
- **Location C:** 75% across the width

These are *prototype* locations designed to be deterministic and reproducible. Future clinical validation would map these directly to recognized anatomical landmarks.

## 5. Mathematical Method
The system uses a geometric proxy for thickness:
1. Extract bounding box.
2. Locate the specific columns corresponding to Locations A, B, and C.
3. Determine the vertical bounds (top-most non-zero pixel and bottom-most non-zero pixel) in that column.
4. Calculate vertical thickness (in pixels).

## 6. Calibration
The `CalibrationService` manages the physical scale of the image by extracting `PixelSpacing` from DICOM metadata.
- **Pixels:** Always calculated.
- **Millimeters (mm):** Calculated *only* if the calibration service can supply a valid `pixel_spacing` value.
- **Anisotropic Scaling:** The system respects independent horizontal and vertical spacing values. Meniscus thickness uses the vertical (`row_mm`) spacing.

## 7. Demo Mode limitations
If the underlying segmentation was generated by the `DemonstrationSegmentationModel`, the measurement engine explicitly flags the resulting measurements with a warning. 
**No clinical decisions** should be made on this data.

## 8. Validation
Synthetic geometric tests exist in `tests/test_measurements.py` asserting that the algorithm correctly deduces thickness on known grid structures (rectangles). Repeatability tests enforce that calling the endpoint twice on the same image yields mathematically identical results.
